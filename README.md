# CNS 3205 GitHub Workflow

This project demonstrates the integration of a Linux virtual cloud server with GitHub.

## Technologies Used

- Ubuntu Linux
- Git
- GitHub
- SSH
- Bash
- YAML
- GitHub Actions

## Project Purpose

The purpose of this project is to demonstrate how source code can be managed on a Linux server using Git and synchronized with a GitHub repository.

## Workflow

The basic workflow is:

1. Create or modify code.
2. Check the changes using Git.
3. Stage the changes.
4. Commit the changes.
5. Push the changes to GitHub.
6. Pull updates from GitHub when required.
